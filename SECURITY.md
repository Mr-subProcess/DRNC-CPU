# Security and responsible disclosure

RAQM is a hardware/RTL prototype and has not undergone a security assessment. Do not connect an unreviewed build to safety-critical, industrial-control or production networks.

For vulnerabilities in a private deployment, contact the project maintainer through the private contact route associated with the repository rather than posting credentials, proprietary bitstreams, keys or customer data in a public issue. No maintainer contact address is embedded in this package because none has been designated.
