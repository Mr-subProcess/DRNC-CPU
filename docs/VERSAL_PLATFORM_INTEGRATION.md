# Versal platform integration guide (G77M)

This is a platform handoff guide, not a generated CIPS/NoC block design. Use the exact G77M SOM order code and the matching carrier/development-board files before assigning pins or enabling transceivers.

## 1. Recommended platform structure

1. Add Versal CIPS and configure a PL fabric clock from `PL0_REF_CLK` (start with 100 MHz for functional bring-up; this is not the maximum operating frequency).
2. Add Processor System Reset and use the CIPS-derived PL reset for the platform. Feed the active-low reset into `aresetn_async`; the RAQM wrapper synchronizes deassertion.
3. Instantiate `raqm_versal_g77m_top` as RTL module reference or package it as custom IP.
4. Connect CIPS `M_AXI_FPD` through AXI SmartConnect to RAQM `S_AXI`.
5. Add AXI DMA in simple mode for first bring-up. Configure MM2S and S2MM stream widths to 256 bits, where supported by the selected Vivado IP configuration.
6. Connect DMA `M_AXIS_MM2S` to RAQM `S_AXIS`; connect RAQM `M_AXIS` to DMA `S_AXIS_S2MM`.
7. Connect DMA memory-mapped masters to the CIPS/NoC path and PS DDR using the topology generated by the selected Versal platform design. Do not hand-guess the NoC port connectivity.
8. Use the same PL clock for RAQM AXI-Lite and AXI-Stream interfaces. If using another clock, add the correct AXI Clock Converter and AXI4-Stream Clock Converter; do not cross clock domains with direct wires.
9. For initial DMA operation, set RAQM `CTRL.CFG_OVERRIDE=1` and program `CFG` through AXI-Lite. DMA generally does not create the RAQM per-beat TUSER command structure automatically; add a packetizer/sideband source if per-beat control is required.
10. The output `TUSER` is a status byte. Confirm the chosen sink preserves TUSER; otherwise use the AXI-Lite counters/last-status register or a dedicated metadata side channel.

## 2. Data-plane connections

| RAQM port | Connect to | Notes |
|---|---|---|
| `S_AXIS` | AXI DMA `M_AXIS_MM2S` | 256-bit data; TKEEP must be all ones |
| `M_AXIS` | AXI DMA `S_AXIS_S2MM` | 256-bit data; status is TUSER; TLAST pass-through |
| `S_AXI` | AXI SmartConnect from CIPS `M_AXI_FPD` | 32-bit AXI-Lite address/data |
| `aclk` | Common PL fabric clock | 100 MHz initial target only |
| `aresetn_async` | PL reset, active low | deassertion synchronized internally |

The AXI DMA may require matching stream width and compatible memory-side widths. If the NoC/DDR path is wider or narrower, use the supported interconnect/data-width conversion provided by Vivado and verify alignment, burst and cache-coherency behavior in software.

## 3. CIPS/NoC platform notes

AMD UG1305 provides the CIPS PS-PL interface and NoC/DDR configuration flows. Exact CIPS properties and NoC connectivity depend on Vivado release, device/package, memory population and board support platform. Prefer the iWave-supplied G77M platform files or a vendor reference design over hard-coded generated CIPS property dictionaries from another board.

## 4. Carrier-board freeze gates

Do not create final XDC or PCB pin assignments until all of these are known:

- iWave orderable SOM part number and full SoC speed/temperature grade.
- exact 2VE3858 package and Vivado `PART` string.
- G77M datasheet/hardware manual revision and complete B2B1/B2B2/B2B3 connector tables.
- carrier mating connector and stack-height confirmation.
- every used bank's VCCO and I/O standard.
- power-up/down sequencing, current budget, inrush and thermal design.
- selected GTYP quad, refclock pins, lane map, AC coupling and protocol.

The current G77M datasheet REL0.1 describes XC2VE3858/SSVA2112 compatibility, but its orderable product part-number table is marked TBD. Obtain written confirmation from iWave before purchasing or freezing the carrier board.

## 5. High-speed links

Do not call the RAQM 256-bit AXI stream a 100G interface by itself. A 100G/PCIe/10GbE external link requires the corresponding Versal GTYP configuration, MAC/PCS or PCIe IP, reference clock, transceiver constraints, connector/cage, channel-loss budget, SI/PI simulation and link-level BER validation. The Rev 4 RTL has no completed MAC/PCS/GTYP subsystem.
